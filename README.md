# Ezanshu SkinFix website

Static website for GitHub Pages.

## Preview
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a public GitHub repository.
2. Upload everything in this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you a `github.io` URL.

## Add/replace screenshots
Put replacement images in `assets/` and keep the filenames used by `index.html`.

## Update extension
Replace `download/ezanshu_skinfix_V1_FINAL.zip` with the newest ZIP and update the version text/hash/scan evidence in `index.html`.
