The extension's popup includes three areas: Textures, Skin Changer, and About. The supplied release includes the Dark Nostalgia texture pack, a loading-screen replacement, and user-configurable skin mappings.

What happens under the hood

  • Uses Chrome's declarativeNetRequest for local redirect rules.
  • Stores extension settings with Chrome storage.
  • Targets EvoWorld pages under evoworld.io and its subdomains.
  • Texture redirects use files bundled inside the extension.
  • Skin redirects preserve the EvoWorld sprite host instead of hard-coding one CDN hostname.
  • Sprite query strings are tolerated, and multiple resource types are supported.

Permissions & access

The V1 manifest declares declarativeNetRequest, storage, and webRequest, with host access limited to evoworld.io and its subdomains. These permissions are used for the texture/skin redirect functionality and the extension's rule status/skin observation features.

Install in a few minutes

Because this release is distributed outside the Chrome Web Store, Chrome requires the normal “Load unpacked” developer installation flow.

1

Download

Click Download SkinFix V1 and save the ZIP file.

2

Extract

Right-click the ZIP → Extract All. Keep the extracted extension folder somewhere you won't accidentally delete.

3

Open Extensions

In Chrome, open chrome://extensions.

4

Developer mode

Turn on Developer mode in the top-right corner.

5

Load unpacked

Click Load unpacked and select the extracted extension folder containing manifest.json.

6

Open & use

Open the SkinFix extension, choose Textures or Skin Changer, then use the controls shown in the screenshots above.

FAQ

Is SkinFix free?

Yes. The V1 release is provided free of charge.

Why do I have to use Load unpacked?

This release is distributed as a ZIP instead of through the Chrome Web Store, so Chrome's developer installation flow is required.

Does the VirusTotal result guarantee safety?

No scan can guarantee future safety. The displayed result documents the exact V1 ZIP that was analyzed at that time.

Will I need to repeat setup after every browser restart?

Normally an unpacked extension remains installed while its folder is available. If Chrome disables it or the extension files change, follow Chrome's extension-management instructions.
